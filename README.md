# 🎮 Don't Push Me! — วิ่งหนีตาย ขัดขาเพื่อน

เกม 2D Side-scroller ฮาๆ เล่นผ่านเว็บแชร์วง LAN เล่นกับเพื่อนได้ผ่าน Browser!  
ผู้เล่นต้องแข่งกันวิ่งจาก **จุด A** ไปยัง **จุด B (เส้นชัย)** โดยใช้ทริคการผลัก, ดึงแกล้งเพื่อน หรือสับสวิตช์ทิ้งเพื่อนลงเหว!

---

## 🚀 วิธีติดตั้งและรันเกม (How to Run)

1. เข้ามายังโฟลเดอร์ของโปรเจกต์:
   ```powershell
   cd "d:\dont push me"
   ```

2. ติดตั้ง Dependencies (Express & Socket.io):
   ```powershell
   npm install
   ```

3. รัน Server ด้วย Port ที่กำหนด (**7488**):
   ```powershell
   npm start
   ```
   *หมายเหตุ: สามารถกำหนด Port อื่นๆ ได้ด้วยตัวเลือก `--port` เช่น:*
   ```powershell
   node server.js --port 8080
   ```

4. เปิด Browser แล้วพิมพ์ที่อยู่ของแต่ละเครื่อง:
   * **เครื่อง Host (คนเปิดเซิร์ฟ):** เปิด `http://localhost:7488`
   * **เครื่องคนอื่นๆ ในวง LAN เดียวกัน:** พิมพ์ IP ของเครื่อง Host เช่น `http://192.168.1.50:7488` (สามารถหา IP Host ได้จากการพิมพ์ `ipconfig` ใน command prompt)

## ☁️ ลงให้เล่นออนไลน์ (Render)

1. push โค้ดขึ้น GitHub แล้วเข้า [render.com](https://render.com) → **New → Blueprint** → เลือก repo นี้ (เลือกสาขาที่ต้องการ deploy)
2. Render อ่านไฟล์ `render.yaml` ให้เอง (โซนสิงคโปร์ เครื่องเดียว ไม่หลับ) กด **Apply**
3. รอ build เสร็จ จะได้ลิงก์ `https://dont-push-me-xxxx.onrender.com` ส่งให้เพื่อนเข้าเล่นได้เลย
4. เช็กว่าเซิร์ฟเวอร์ยังอยู่: เปิด `/healthz` ต่อท้ายลิงก์

ข้อควรรู้: ห้องเก็บอยู่ในหน่วยความจำของเซิร์ฟเวอร์ ดังนั้นต้องใช้ **เครื่องเดียว** และถ้าเซิร์ฟเวอร์รีสตาร์ท (เช่น deploy ใหม่) ห้องที่กำลังเล่นอยู่จะหาย แพ็กเกจฟรีของ Render จะหลับเมื่อไม่มีคนใช้ จึงไม่เหมาะกับเกมนี้

### 😮 อม พ่น และพลังจากดาว (สไตล์ Kirby)

* **อมดาว ⭐** = ได้พลังสุ่ม ใช้ได้ 15 วินาที (ปีก 10 วินาที) ใช้ด้วยปุ่ม <kbd>V</kbd> (การ์ดพลังด้านล่างจอบอกวิธีใช้เสมอ)
  * 🔥 **ไฟ** — พ่นลูกไฟพุ่งไปข้างหน้า ชนใครคนนั้นกระเด็น
  * ❄️ **น้ำแข็ง** — แช่แข็งคนที่อยู่ข้างหน้า 1 วินาที
  * 🌀 **ปั่น** — หมุนติ้วชนทุกคนรอบตัวให้กระเด็น เดินเร็วขึ้นด้วย
  * 🪽 **ปีก** — ไม่ต้องกด V: กดกระโดดซ้ำกลางอากาศเพื่อกระพือปีกลอยขึ้น กดค้างเพื่อร่อน
* **อมผลไม้ 🍎** — เก็บไว้ในปาก แล้วพ่นออกมาเป็นดาวพุ่งใส่คนอื่น
* **อมเพื่อน!** — ถ้าเพื่อนอยู่ในระยะ เพื่อนจะถูกดูดเข้าไป (หนีได้ถ้าวิ่งหนีทัน) พอกลืนแล้วจะพ่นเพื่อนออกไปเป็น "ลูกโบว์ลิ่ง" ชนคนอื่นกระเด็น หรือพ่นลงเหวก็ได้โบนัส KO
  * คนที่ถูกกลืน **กดปุ่มเดิน/กระโดดรัวๆ 6 ครั้ง** เพื่อหนีออกมา ไม่งั้นจะถูกพ่นเองใน 3 วินาที
  * คนที่ถูกพ่นออกมา **ไม่ได้ตายแน่นอน**: ตกช้าลงเล็กน้อย และมี **กระโดดเบรกกลางอากาศ 1 ครั้ง** (กด Space ภายใน ~0.5 วินาทีหลังถูกพ่น) แล้วเดินกลับเข้าฝั่งได้ ใครพ่นลงเหวแล้วเหยื่อไม่ทันกดก็ยังได้ KO
  * **ยิ่งอมนาน ยิ่งพ่นแรง**: ความแรงของการพ่น **คน** (ทั้งความเร็วและแรงชน) เพิ่มตามเวลาที่อมไว้ สูงสุดเมื่อครบ 3 วินาที (แรงขึ้นเกือบ 2 เท่า) ตัวคนอมจะพองขึ้นและมีแถบบอกความแรง แต่ถ้าอมนานเหยื่อก็มีเวลาดิ้นหนีมากขึ้น และพ่นแรงสุดจะเหลือเวลากระโดดเบรกแค่ ~0.3 วินาที
  * คนพ่นอมซ้ำทันทีไม่ได้ (รอ ~1 วินาที) และคนที่เพิ่งหลุดจะอมซ้ำไม่ได้ ~1.5 วินาที
  * 🪽 ปีกกระพือได้ 8 ครั้งต่อการได้พลัง หลังจากนั้นร่อนได้อย่างเดียว (กันบินข้ามทั้งด่าน)

> ถูกดึง (Pull) แล้ว **กดปุ่มเดิน/กระโดดรัวๆ** เพื่อสลัดหลุดเร็วขึ้น หลังหลุดจะมีภูมิคุ้มกันถูกดึงซ้ำประมาณ 1 วินาที

### ⌨ ตั้งค่าปุ่ม

กด **ตั้งค่าปุ่ม** ที่เมนูหรือห้องรอ (หรือลิงก์ "เปลี่ยนปุ่ม" ในหน้าวิธีเล่น): กดช่องที่ต้องการ แล้วกดปุ่มใหม่บนคีย์บอร์ด (Esc = ยกเลิก, Backspace = ลบปุ่มในช่องนั้น) ทุกคำสั่งมีได้ 3 ปุ่ม ปุ่มหนึ่งใช้ได้กับคำสั่งเดียว (ถ้าซ้ำจะย้ายมาให้และบอกว่าคำสั่งไหนเสียปุ่ม) ปุ่มของเบราว์เซอร์อย่าง Esc/Tab/F1–F12 ใช้ไม่ได้ ถ้าคำสั่งสำคัญไม่เหลือปุ่ม ระบบเลือกปุ่มว่างให้เอง ค่าจำไว้ในเบราว์เซอร์ และข้อความ/ป้ายปุ่มในเกมเปลี่ยนตามที่ตั้ง

### ตั้งค่าห้อง

หัวหน้าห้องเลือกในห้องรอ (คนอื่นเห็นค่าที่เลือก): **ผู้เล่นสูงสุด** (4/6/8 คน ค่าเริ่มต้น 8), **จำนวนด่านที่เล่น** (1-8 ด่าน), **หัวใจต่อรอบ** (1/3), **ดาว/ผลไม้ เปิด-ปิด**, **ลำดับด่าน** (สุ่มไม่ซ้ำ หรือเรียงตามลำดับ) รหัสห้องเป็น **เลข 6 หลัก** เดายากกว่าเดิม

### ลิงก์เชิญและเชิญคนออก

* ในห้องรอกด **คัดลอกลิงก์เชิญ** ส่งให้เพื่อน เพื่อนเปิดแล้วรหัสห้องถูกกรอกให้ (แค่ใส่ชื่อแล้วกดเข้าร่วม)
* หัวหน้าห้องกดปุ่มวงกลมขีดฆ่าข้างชื่อผู้เล่นในห้องรอเพื่อ **เชิญออก** (ทำได้เฉพาะก่อนเริ่มเกม)

### 📱 เล่นบนมือถือ

เปิดลิงก์เกมบนมือถือ/แท็บเล็ตได้เลย ระบบแสดงปุ่มบนจอให้อัตโนมัติ (คอมพิวเตอร์ไม่เห็นปุ่มพวกนี้):

* **แถบซ้าย-ขวา** เดิน (ลากนิ้วสลับซ้าย/ขวาได้โดยไม่ต้องยกนิ้ว) • **ลูกศรขึ้น** กระโดด
* **ดาวระเบิด** ผลัก • **แม่เหล็ก** ดึง • **หน้าอ้าปาก** กดค้างเพื่ออม กดอีกครั้งเพื่อพ่น • **ไอคอนพลัง** ใช้พลังจากดาว (จางเมื่อไม่มีพลัง) • **ฟองคำพูด** เปิดแถบอีโมจิ
* กดได้หลายนิ้วพร้อมกัน (เช่น เดินพร้อมกระโดดพร้อมอม)
* **หมุนจอเป็นแนวนอน** (ถ้าถือแนวตั้งจะมีข้อความเตือน) และกดปุ่มเต็มจอมุมขวาบนเพื่อซ่อนแถบเบราว์เซอร์
* ลองบนคอมเพื่อดูหน้าตาปุ่มสัมผัส: เปิดลิงก์ต่อท้ายด้วย `?touch`

### ❤ หัวใจและเช็กพอยต์ (เกิดใหม่)

* แต่ละคนมี **หัวใจ 3 ดวงต่อด่าน** ตาย (ตกเหว โดนหนาม โดนลาวา) แล้วรอ 3 วินาที จะฟื้นที่ **ธงเช็กพอยต์ล่าสุดที่ผ่านมา** (ธงจะเปลี่ยนจากสีเทาเป็นสีชมพูเมื่อบันทึกแล้ว) ถ้ายังไม่ผ่านธงไหนเลยจะเกิดที่จุดเริ่มต้น
* ฟื้นแล้วอมตะ 2 วินาที (ตัวกะพริบ) กันตายซ้ำที่เดิม แต่จะเสียพลังที่ถืออยู่
* หัวใจหมดคือออกจากรอบนั้น (ดูเพื่อนเล่นต่อ) รอบจบเมื่อทุกคนเข้าเส้นชัย หัวใจหมด หรือหมดเวลา
* ด่านลาวา: ถ้าลาวาท่วมธงที่ต้องฟื้นไปแล้ว จะฟื้นไม่ได้ (ออกจากรอบ)
* **สะพานที่ถูกตัดกลับมาเอง** หลังผ่านไป 7 วินาที (เส้นประจะค่อยๆ เข้มขึ้นแล้วกะพริบก่อนกลับ) กันไม่ให้ใครถูกขังอยู่ฝั่งเดียวจนจบด่าน ส่วนการตัดสะพานทิ้งตอนที่คนตามมาอยู่บนสะพานยังได้ผลเหมือนเดิม
* โบนัส KO ยังได้ทุกครั้งที่ส่งเพื่อนลงเหว (สูงสุด 3 ครั้งต่อคนต่อรอบ)

### 👕 แต่งตัว (สกิน)

กดปุ่ม **👕 แต่งตัว** ที่หน้าเมนูหรือในห้องรอ (เปลี่ยนในห้องรอได้ เพื่อนเห็นทันที) มีตัวอย่างสดให้ดูก่อนเลือก:

| หมวด | ตัวเลือก |
| :--- | :--- |
| **สี** (16 สี) | ชมพู ฟ้า เหลือง เขียว ม่วง ส้ม มิ้นต์ แดง ขาว เทา น้ำตาล เลมอน ฟ้าทะเล ปะการัง ทอง คราม |
| **หน้า** (13 แบบ) | ปกติ ยิ้มแป้น ง่วงนอน ยิ้มมุมปาก โกรธ แมวเหมียว ตาเหล่ ตกใจ ขยิบตา ตาวิบวับ เบื่อโลก ร้องไห้ และ **อาเบะ ยาราไนกะ** (เอารูปจริงมาแปะบนตัวการ์ตูนแบบเรียบๆ ให้ตัดกัน รูปอยู่ที่ `public/img/abe.png` เปลี่ยนไฟล์นี้เพื่อเปลี่ยนรูปได้) |
| **หมวก** (22 แบบ) | มงกุฎ หมวกแก๊ป หมวกไหมพรม หมวกปาร์ตี้ หูแมว หูกระต่าย หมวกเชฟ รัศมีนางฟ้า ดอกไม้ หมวกทรงสูง ผ้าคาดหัว เขาปีศาจ หมวกโจรสลัด หมวกพ่อมด หมวกคาวบอย ต้นอ่อน หมวกนิรภัย หูฟัง หมวกซานต้า โบว์ หมวกเห็ด |

* เป็นแค่หน้าตา **ไม่มีผลกับการเล่น** (ขนาดตัว/ฟิสิกส์เท่ากันทุกแบบ) ค่าที่เลือกจำไว้ในเบราว์เซอร์ และเซิร์ฟเวอร์ตรวจให้ ส่งค่าแปลกๆ มาไม่ได้
* ตอนได้พลังไฟ/น้ำแข็ง/ปั่น หมวกพลังจะมาแทนหมวกที่ใส่ไว้ชั่วคราว
* ข้อมูลทั้งหมดอยู่ที่ `shared/skins.js` ถ้าจะเพิ่มของใหม่ เพิ่มที่นั่นและเพิ่มท่าวาดใน `public/js/renderer.js`

### ⚡ ความลื่นของการควบคุม

* ตัวละครของคุณขยับ **ทันทีที่กดปุ่ม** ไม่รอเซิร์ฟเวอร์ (client-side prediction) เซิร์ฟเวอร์ยังเป็นผู้ตัดสินสุดท้าย และคอยแก้ให้ตรงกันถ้ามีอะไรไม่ตรง (เช่นโดนผลัก) ฟิสิกส์การเดิน/กระโดดอยู่ที่ `shared/movement.js` ใช้ร่วมกันทั้งสองฝั่ง
* กระโดดง่ายขึ้น: กดก่อนถึงพื้นเล็กน้อยก็ติด (jump buffer 120ms) และกระโดดได้อีกนิดหลังเดินพ้นขอบ (coyote time 100ms)
* มุมซ้ายบนมีตัวเลขปิง (📶) ถ้าเกิน ~150ms คนอื่นจะดูกระตุก/ช้า แต่ตัวคุณเองยังลื่น
* จบแมตช์แล้ว หัวหน้าห้องกด **เล่นอีกรอบ** เพื่อกลับห้องรอได้เลย ไม่ต้องสร้างห้องใหม่
* **ออกจากห้อง:** มีปุ่มในห้องรอ (ปุ่ม "ออกจากห้อง"), ระหว่างเล่น (ปุ่ม 🚪 มุมขวาบน จะถามยืนยันก่อน) และหน้าสรุปคะแนน ออกแล้วที่นั่งว่างทันที ถ้าหัวหน้าห้องออก คนถัดไปจะเป็นหัวหน้าแทน

## 🗺️ ด่านทั้ง 5 ด่าน (Levels)

ทุกด่านยาวกว่าเดิมหลายเท่า (จำกัดเวลา 150 วินาที) และมีดาว ⭐ กับผลไม้ 🍎 วางไว้ให้เก็บ (ของจะกลับมาเกิดใหม่หลังถูกกิน)

1. **ด่าน 1: สะพานมรณะ (The Bridge of Death)** — ทุ่งหญ้า ยาว 6,500 px
   * สะพานไม้ข้ามเหวหนาม มีสวิตช์อยู่ปลายสะพาน ถ้าข้ามไปแล้วกดสับสวิตช์ทิ้งสะพานด้านหลัง เพื่อนที่ตามมาจะตกร่วงลงไป!
2. **ด่าน 2: โรงงานหนาม (Spike Factory)** — โลกลูกกวาด ยาว 8,500 px
   * ชานชาลาลอยฟ้าต่อกันยาวเหยียด มีหนามที่เดินไปมาและสะพานไม้ที่ตัดทิ้งได้
3. **ด่าน 3: หอคอยลาวาเดือด (Lava Tower)** — ภูเขาไฟ สูง 3,400 px
   * ปีนขึ้นแนวดิ่ง ลาวาค่อยๆ สูงขึ้น ใครช้าก็ไหม้ ดึงหรือกลืนเพื่อนไว้ข้างล่างให้โดนเผา

4. **ด่าน 4: ผาลมพัดยามเย็น (Windy Dusk)** — ธีมพระอาทิตย์ตก ยาว 6,600 px
   * **ลมพัด** (ลูกศรขาว) ดันตัวคุณถอยหลังหรือไปข้างหน้า และ **แพลตฟอร์มกะพริบ** (สีฟ้าเรืองแสง) ที่ตั้งอยู่ 2.4 วินาทีแล้วหายไป 1.4 วินาที กะพริบถี่ก่อนหาย
5. **ด่าน 5: โรงเลื่อยยามค่ำ (Night Saw Mill)** — ธีมกลางคืน ยาว 5,200 px
   * **ใบเลื่อยหมุนวน** ลอยกลางอากาศ และ **โซนแรงโน้มถ่วงต่ำ** (ฟองสีม่วง) ที่กระโดดลอยไกลมาก ใช้ข้ามเหวกว้าง

### 🏟️ โหมดอยู่รอด (Survival) และพลังใหม่
* หัวหน้าห้องเลือก **โหมด: อยู่รอด** ได้ในห้องรอ เล่นบนสนามเล็กหน้าจอเดียว (2 สนาม) พื้นจะ **สั่นเตือน 1.5 วินาที แล้วถล่มลงตามเวลา** จากริมเข้ากลาง คนสุดท้ายที่ยังยืนอยู่ชนะ คะแนนเรียงตามลำดับที่ตกรอบ (ผู้รอด 10 → 8 → 6 → 4 → 2) เกิดใหม่ (ถ้ายังมีหัวใจ) บนพื้นที่ยังอยู่ได้นานที่สุด
* **พลังโล่ (ฟองสีฟ้า):** กันหนาม ลาวา ธนู ลูกไฟ ได้ 1 ครั้ง แล้วแตก (ไม่กันตกเหว) **พลังวิ่งเร็ว (เส้นความเร็วสีเหลือง):** วิ่งเร็วขึ้น ~45% นาน 10 วินาที ทั้งสองอย่างไม่ต้องกดปุ่ม
* บอตหลบธนู/ลูกไฟ (กระโดดข้าม) และหลบหินตก (ก้าวหนี) ได้แล้ว
* **โหมดฝึกเล่น** ปุ่ม "ฝึกเล่น" ที่เมนู: ห้องส่วนตัวกับบอตเพื่อนซ้อม ด่านสั้นที่มีคำใบ้บนหน้าจอสอนตั้งแต่เดิน กระโดด อม พ่น ใช้พลัง สะพาน ไปจนถึงสปริง
* **ตรวจ design:** `node tools/skin-sheet.js` ทำแผ่นภาพรวมการแต่งตัวทุกแบบ (รวมชุดสุ่มหลายชิ้นพร้อมกัน) ดูวิธีตรวจใน `.claude/skills/design-check/SKILL.md`

### 🧱 อุปสรรคและพื้นผิวพิเศษ
* **หนามเดินตรวจ** วิ่งเร็วขึ้นกลับมาที่ ~100 px/s (ก่อนหน้านี้ช้าลงเพราะผมลดระยะเดินให้แคบ แต่ไม่ได้เพิ่มความถี่ ตอนนี้แต่ละตัวมีค่า `freq` ของตัวเอง ความเร็ว = ระยะเดิน × freq)
* **กระดานสปริง (ชมพู)** เหยียบแล้วเด้งขึ้นสูงประมาณ 250 px ใช้ข้ามเหวหรือข้ามชั้นในหอคอย
* **พื้นน้ำแข็ง (ฟ้าอ่อน)** ออกตัวและหยุดช้า ลื่นไถลได้
* **สายพาน (ลูกศรเหลือง)** พาตัวคุณไปตามทิศของลูกศร
* **หินร่วน (มีรอยแตก)** แตะเฉยๆ ไม่แตก ต้องยืนนานราว 1.8 วินาที (เริ่มสั่นตอนยืนเกือบ 1 วินาที) ถ้าลงไปก่อนแรงกดจะค่อยๆ หาย ร่วงแล้วกลับมาเองใน 4 วินาที
* **ปืนใหญ่ธนู** ยิงลูกธนูตามพื้น กระโดดข้ามได้ **ก้อนหินตก** ร่วงลงมาจากเครื่องปล่อยด้านบน และ **ลูกไฟ** (ด่านลาวา) ทั้งหมดโดนแล้วเสียหัวใจเหมือนโดนหนาม
* **แต่ละด่านมีอุปสรรคเฉพาะของตัวเอง ไม่ซ้ำกัน:** ด่าน 1 = สปริง + ปืนใหญ่ธนู · ด่าน 2 = สายพาน + หินร่วน + หินตก · ด่าน 3 = น้ำแข็ง + ลูกไฟพ่นข้ามช่องหอคอย · ด่าน 4 = ลม + แพลตฟอร์มกะพริบ · ด่าน 5 = ใบเลื่อย + แรงโน้มถ่วงต่ำ
* บอตยังไม่หลบธนูและหินตก (บอตมีหัวใจไม่จำกัดอยู่แล้ว)

> ด่านทั้งหมดสร้างจาก `tools/build-levels.js` และตรวจว่า "จบได้จริง" ด้วย `tools/reach.js` (จำลองการกระโดดด้วยฟิสิกส์จริงของเกม) ถ้าแก้ด่านให้รัน `node tools/build-levels.js && node tools/reach.js`

## 🏆 ระบบคิดคะแนน
* เล่นทั้งหมด **3 รอบ (3 Levels)**
* ลำดับคนเข้าเส้นชัยในแต่ละด่านจะได้รับคะแนนตามนี้:
  * อันดับ 1: **+10 คะแนน**
  * อันดับ 2: **+8 คะแนน**
  * อันดับ 3: **+6 คะแนน**
  * อันดับ 4: **+4 คะแนน**
  * ตกรอบ/ตาย: **0 คะแนน**
* **โบนัส KO +3 คะแนน**: ถ้าผลักหรือดึงเพื่อนแล้วเพื่อนตายภายใน 3 วินาที (ลงเหว โดนหนาม ลาวา) คุณจะได้โบนัส แม้ตัวเองจะตายหรือหมดเวลาก็ยังได้
* **ไล่ตาม (Catch-up)**: ผู้เล่นที่ตามหลังผู้นำมากๆ จะผลักแรงขึ้น 20% และคูลดาวน์สั้นลง 25%
* **จำกัดเวลา 150 วินาที** ต่อด่าน ใครยังไม่ถึงเส้นชัยเมื่อหมดเวลาได้ 0 คะแนน
* เมื่อจบด่านที่ 3 ผู้ที่มีคะแนนรวมสูงสุดจะสวม **มงกุฎผู้ชนะ!**
