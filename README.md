# 🎮 Don't Push Me! — วิ่งหนีตาย ขัดขาเพื่อน

เกม 2D Side-scroller ฮาๆ เล่นผ่านเว็บแชร์วง LAN เล่นกับเพื่อนได้ผ่าน Browser!  
ผู้เล่นต้องแข่งกันวิ่งจาก **จุด A** ไปยัง **จุด B (เส้นชัย)** โดยใช้ทริคการผลัก, ดึงแกล้งเพื่อน หรือสับสวิตช์ทิ้งเพื่อนลงเหว!

---

## 🚀 วิธีติดตั้งและรันเกม (How to Run)

1. เข้ามายังโฟลเดอร์ของโปรเจกต์:
   ```powershell
   cd "d:\dont push me"
   ```

2. ติดตั้ง Dependencies (Express & Socket.io):
   ```powershell
   npm install
   ```

3. รัน Server ด้วย Port ที่กำหนด (**7488**):
   ```powershell
   npm start
   ```
   *หมายเหตุ: สามารถกำหนด Port อื่นๆ ได้ด้วยตัวเลือก `--port` เช่น:*
   ```powershell
   node server.js --port 8080
   ```

4. เปิด Browser แล้วพิมพ์ที่อยู่ของแต่ละเครื่อง:
   * **เครื่อง Host (คนเปิดเซิร์ฟ):** เปิด `http://localhost:7488`
   * **เครื่องคนอื่นๆ ในวง LAN เดียวกัน:** พิมพ์ IP ของเครื่อง Host เช่น `http://192.168.1.50:7488` (สามารถหา IP Host ได้จากการพิมพ์ `ipconfig` ใน command prompt)

## 🕹️ วิธีการเล่นและควบคุม (How to Play)

ทุกคนใช้คีย์บอร์ดของตัวเองในการควบคุมผ่านหน้าเว็บเบราว์เซอร์:

| การกระทำ | ปุ่มกด | รายละเอียด |
| :--- | :---: | :--- |
| **เคลื่อนที่ ซ้าย/ขวา** | <kbd>A</kbd> / <kbd>D</kbd> หรือ <kbd>←</kbd> / <kbd>→</kbd> | เดินหลบสิ่งกีดขวางและอุปสรรค |
| **กระโดด** | <kbd>W</kbd> / <kbd>↑</kbd> / <kbd>Space</kbd> | กระโดดขึ้นแพลตฟอร์ม |
| **💥 ผลัก (Push)** | <kbd>F</kbd> / <kbd>Z</kbd> | ผลักผู้เล่นใกล้ตัวกระเด็นไปด้านหน้า (Cooldown 1.2 วินาที) |
| **🧲 ดึงขัดขา (Pull)** | <kbd>G</kbd> / <kbd>X</kbd> | ดึงผู้เล่นข้างหน้าไว้ให้อยู่กับที่ชั่วคราว 1.5 วินาที (Cooldown 2.5 วินาที) |
| **🔘 เปิด-ปิดสวิตช์** | <kbd>E</kbd> | สับสวิตช์เปิด-ปิดการแสดงผลของสะพานสีส้ม เพื่อแกล้งให้เพื่อนร่วง |
| **😂 อีโมจิ** | <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> <kbd>4</kbd> | ส่งอีโมจิลอยเหนือหัว 😂 😡 👋 💀 (ส่งได้วินาทีละครั้ง) |
| **🔊 เปิด/ปิดเสียง** | <kbd>M</kbd> | หรือกดปุ่มลำโพงบนหน้าจอ |
| **👀 ดูเพื่อน (ตอนตายหรือเข้าเส้นชัยแล้ว)** | <kbd>A</kbd> / <kbd>D</kbd> | สลับไปดูผู้เล่นคนอื่นที่ยังวิ่งอยู่ |

> ถูกดึง (Pull) แล้ว **กดปุ่มเดิน/กระโดดรัวๆ** เพื่อสลัดหลุดเร็วขึ้น หลังหลุดจะมีภูมิคุ้มกันถูกดึงซ้ำประมาณ 1 วินาที

## 🗺️ ด่านทั้ง 3 ด่าน (Levels)

1. **ด่าน 1: สะพานมรณะ (The Bridge of Death)**
   * สะพานทางผ่านข้ามเหวหนามสุดหวาดเสียว มีสวิตช์ตั้งอยู่ระหว่างทาง ถ้าข้ามไปแล้วลองกดสับสวิตช์ทิ้งสะพานด้านหลัง เพื่อนด้านหลังจะตกร่วงลงไปตาย!
2. **ด่าน 2: โรงงานหนาม (Spike Factory)**
   * ด่านแพลตฟอร์มลอยฟ้าที่มีหนามเคลื่อนที่เลื่อนไปเลื่อนมาคอยดักขวางทาง คอยผลักดันให้เพื่อนกระเด็นชนหนาม!
3. **ด่าน 3: หอคอยลาวาเดือด (Lava Tower)**
   * ด่านขึ้นแนวดิ่งสุดท้าทาย ลาวาร้อนระอุจะค่อยๆ เพิ่มความสูงจากข้างล่างขึ้นมาเรื่อยๆ ทุกคนต้องรีบปีนขึ้นไปให้สูงที่สุด ดึงเพื่อนไว้ให้อยู่ข้างล่างให้โดนเผาตาย!

## 🏆 ระบบคิดคะแนน
* เล่นทั้งหมด **3 รอบ (3 Levels)**
* ลำดับคนเข้าเส้นชัยในแต่ละด่านจะได้รับคะแนนตามนี้:
  * อันดับ 1: **+10 คะแนน**
  * อันดับ 2: **+8 คะแนน**
  * อันดับ 3: **+6 คะแนน**
  * อันดับ 4: **+4 คะแนน**
  * ตกรอบ/ตาย: **0 คะแนน**
* **โบนัส KO +3 คะแนน**: ถ้าผลักหรือดึงเพื่อนแล้วเพื่อนตายภายใน 3 วินาที (ลงเหว โดนหนาม ลาวา) คุณจะได้โบนัส แม้ตัวเองจะตายหรือหมดเวลาก็ยังได้
* **ไล่ตาม (Catch-up)**: ผู้เล่นที่ตามหลังผู้นำมากๆ จะผลักแรงขึ้น 20% และคูลดาวน์สั้นลง 25%
* **จำกัดเวลา 90 วินาที** ต่อด่าน ใครยังไม่ถึงเส้นชัยเมื่อหมดเวลาได้ 0 คะแนน
* เมื่อจบด่านที่ 3 ผู้ที่มีคะแนนรวมสูงสุดจะสวม **มงกุฎผู้ชนะ!**
